# LeadPilotAI 软件说明

## 软件简介

LeadPilotAI 是一款基于 BillionMail 深度定制的外贸营销拓客软件，面向有海外市场拓展和客户开发需求的团队，辅助开展外贸营销工作。

本项目仓库当前提供的是软件简介。具体功能、界面和部署方式请以实际发布版本为准。

## 适用场景

- 外贸企业开展海外市场营销和客户拓展
- 营销团队组织外贸邮件营销相关工作
- 需要根据营销反馈持续优化客户开发工作的团队
