# 资料中心模板与邮件统计优化

资料中心的产品列表、资料库工具栏和上传弹窗提供 XLSX 模板，上传弹窗另提供图片 ZIP 结构模板。下载继承公司与部门范围及上传权限，产品模板另要求产品导入权限。

产品模板使用现有解析器支持的字段，并以文本保留 SKU、OE 等编号的前导零。说明与示例放在保留的说明页，实际导入时跳过；空模板不会创建示例产品。公司模板不填写虚构公司资料，由用户填写后走现有识别、人工确认和发布流程。图片包说明对应现有 SKU 或相对路径匹配规则。

优化前线上约 3700 条发送记录：最近一天统计约 24.219 秒，最近七天约 41.855 秒。瓶颈为多次重复扫描与逐收件人关联查询，尤其带尖括号的 Message-ID 及大小写归一化收件地址无法使用普通索引。

统计改为一次数据库快照汇总总览、服务商与各图表，增加与实际比较表达式一致的索引，取消查询失败时假装返回全零的行为。保留按收件地址精确归因、未启用跟踪的口径，以及原时间筛选范围。页面自动刷新期间不再叠加相同的慢请求；未增加统计结果缓存。

线上索引提前以 CONCURRENTLY 建立，再发布应用，避免在启动迁移时长时间阻塞数据写入。部署前备份数据库、邮件、队列与原程序；不重建数据库，不修改邮箱、密码、SES 凭证或 MX 解析。

拓客计划列表补齐“所属公司”的中英日翻译，后端随已授权的计划记录返回 company_name。即使用户没有独立公司资料列表权限，也能看到自己计划所属的公司名称。前端保留旧接口兼容，并统一字符串与数字 ID 的比较。
