# 拓客计划产品可选

新建、编辑、启用和运行拓客计划不再要求至少选择一个产品。省略 product_ids、null 或空数组均表示不限定具体产品，不会自动展开为全部产品。

未选择产品时，搜索关键词和开发信使用拓客需求、已发布的公司资料以及允许 AI 使用的公开资料。用户需求作为活动目标，不作为已经核实的产品规格。资料快照保留公司和素材版本；发送前继续检查权限、版本变化、暂停、退订、收件验证和已回复状态。公司资料模式不依赖产品列表权限。

选择了产品时仍要求属于当前公司且已经发布，最多 100 个。目标市场依然必须为 1–30 个，发件箱、时间窗口、发送额度等校验不变。前端明确标注“产品可选”，保留搜索分页与已选项。

回归使用独立数据库和 AI 模拟器；线上仅创建暂停的内部验收计划验证保存与编辑，并仅清理这些验收记录，不执行 AI 搜索或邮件发送。

同时调整全部 7 个订阅、退订及确认、成功页面。补齐移动端 viewport，使用 BESTMAPLE 商务配色，正文和输入框 18px，输入框及按钮最小高度 58px；电脑端卡片最大宽度 640px，手机端按钮纵向排列，保留缩放、键盘焦点、短屏滚动和安全区域。页面内联样式不依赖外部字体、图片或 CDN。

浏览器检查覆盖 320px、393px、1440px 三种宽度的全部页面，共 21 种组合，无横向溢出。订阅表单提交地址、token 传递以及所有原有 JavaScript 保持一致；页面显示检查不触发真实订阅或退订。
