# HTML 邮件回复预览修复

邮箱端的 HTML 回复使用独立的原邮件只读预览，回复输入区不再包含可编辑的历史邮件。原邮件在底层正文中保留，用于发送、草稿恢复和内嵌附件引用；隐藏规则只作用于本地编辑器，不写入待发送正文。

预览 iframe 使用沙盒隔离，禁用脚本、表单、父页面导航及编辑。中、英、日文提示随邮箱界面语言切换。新邮件、转发和纯文本回复保持原有流程。

同时发布联系人 Excel 导入的待确认地址复选框：默认排除，明确勾选后导入；无效、关键词过滤、重复和仍在验证的行不导入。

验证包含实际 TinyMCE 浏览器交互、HTML 引用/表格/内嵌图片保留、PHP 语法及回复钩子检查；联系人导入使用独立测试数据库验证，前端构建和多语言检查通过。线上更新不重建或删除数据库及邮箱数据。
