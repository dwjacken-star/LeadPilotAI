# 领客AI · LeadPilot AI 交付说明

## 界面与品牌

- 中文名称「领客AI」，英文名称「LeadPilot AI」。登录页、导航、邮件入口、默认页脚、订阅/退订页与项目说明同步更新。
- 使用用户提供的带文字 Logo；折叠菜单使用无文字图形。网站 ICO 包含 16、24、32、48、64、128、256 像素尺寸。
- 「智能情报获客」菜单位于「社媒营销」和「AI智能拓客」之间。
- 统一工作区颜色、表格、卡片、按钮、明暗主题和窄屏布局；移除指向 BillionMail 项目的帮助链接及入口。
- 保留内部 Go 模块、邮件协议标识、部署目录和容器服务名称，避免更新破坏已有账号、数据库、存储和收发服务；许可证及第三方版权声明保留。

## 社媒营销

- 发布任务可删除。删除停止未执行的发布与处理任务，保留必要历史，不删除社交平台上已经发布的帖子。发布中或处理中的任务需要等待执行结束。
- 内容版本标签支持左右箭头滚动。
- 草稿保存具有前端请求合并和后端请求键防重；连续点击、并发提交和请求重试保持同一任务。
- 开始日期仅选择日期。每个市场继续使用独立时区和时分秒，修改日期不会覆盖市场时间。
- 一个任务可选择多个已授权账号；每个市场版本分别为匹配平台的每个账号创建投递记录。
- 列表、日历、效果分析及统计导出支持平台和账号筛选，后台保持权限范围。
- 效果分析增加手动平台数据同步；自动同步固定为四小时。大批量帖子按持久化分页任务同步，避免只刷新前二十条。
- 页面静默轮询只查询本地已保存状态，手动刷新与向社交平台同步为不同操作；后台轮询不会触发刷新按钮反复闪烁。
- 发布记录、账号、互动、处理任务、统计记录也提供对应删除操作；需要相应管理权限。原始回执与必要审计保留。

## 拓客与情报

- AI智能拓客的计划、执行记录、候选公司、线索、开发信、询盘、收件规则、后台任务均可按权限删除。
- 智能情报获客的工作流、执行记录、候选客户、内容、消息事件、情报证据、行业包、业务资料、技能配置和审计列表提供相应删除操作。
- 删除采用逻辑删除。计划停止后续执行，未发送邮件停止，已发送邮件与外部发布不会被撤回。正在执行或发送的记录受保护。
- 删除技能指停用当前公司的技能配置，保留内置技能实现及旧执行快照。系统行业模板和审计列表删除需要管理员权限。
- 采购意向关键词支持 AI 扩词：选择模型、目标国家和语言，生成候选词，勾选并确认后合并去重；不自动覆盖已有关键词，不把扩词当作真实采购证据。

## 千问与 OpenAI

在社媒营销的设置中打开「AI模型服务」，或在 AI智能拓客的 AI 设置中配置。

- 两个服务商分别保存密钥、端点、启用状态和可选模型，密钥加密存储，不返回明文。
- OpenAI 使用官方 Responses API；千问使用阿里云 Model Studio 的 OpenAI 兼容 Chat Completions API。
- 模型使用服务商前缀区分，支持下拉选择及默认文字模型。现有兼容服务继续可用。
- 更换接口地址需要重新填写密钥，防止把已保存凭证转发到其他地址。默认文字模型必须属于启用且已配置的服务商。
- 提供模型发现和已保存配置的实际请求测试；保留调用次数、Token 配额和用量记录。
- 千问支持文字及所选视觉模型支持的图片输入。直接 PDF 文件输入继续使用 OpenAI 或既有支持该能力的服务。图片美化仍使用现有图片服务配置。
- 本次没有提供千问或 OpenAI 的新密钥，不能声称这两个账号已完成真实联网授权或调用验证。协议路由、密钥隔离与结果解析由受控接口测试验证，正式使用前填写账号密钥并执行测试。

官方接口依据：[OpenAI 结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)、[Model Studio Chat Completions](https://help.aliyun.com/en/model-studio/qwen-api-via-openai-chat-completions)。

## 验证与更新

后端使用独立 PostgreSQL 数据库验证，不操作生产业务数据；前端验证包括日期与市场时间隔离、重复保存防护、菜单顺序、格式预览及多语言一致性。前后端生产构建、线上文件校验、API 验收和数据保留检查分别记录。

本轮未完成浏览器视觉验收，也未通过测试向真实客户发邮件或在真实社媒主页发帖。正式平台发布仍受现有授权、内容审核和平台权限控制。

上线前备份数据库、应用、品牌资源和配置。只更新应用与静态资源，采用追加迁移，不删除或重建原数据库。具体镜像、备份目录和线上验收结果记录在 `deploy/LEADPILOT-AI-20261110.json`。
