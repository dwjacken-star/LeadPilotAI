# 邮件参数与退订保护

管理员在设置的常用参数中配置 From、Reply-To，保存立即生效。原环境变量仅用于首次迁移；线上迁移后删除相应环境配置，当前默认仍为 sales@best-maple.com。

Webmail 新邮件、营销任务测试邮件、正式任务和 AI 拓客发送使用相同订阅链接、打开跟踪、点击跟踪和 IP 预热规则。订阅/退订开关开启时自动补充两种有效链接。打开跟踪依赖收件人加载图片，不能据此保证所有实际阅读都被记录。IP 预热是服务器额度控制，不是邮件正文内容。

Webmail 的个性化跟踪与订退链接仅适用于单个收件人；多收件人需关闭个性化选项。附件和原有 HTML 样式保留。正式群发任务仍逐收件人生成独立内容。

退订保存到 bm_delivery_suppressions，历史 unsubscribe_records 自动补入。重新导入或改变分组不会解除退订；营销、API、自动拓客、测试和 Webmail 在 SMTP 前统一拦截。管理端常用参数可查询退订记录。重新订阅须点击确认邮件中的签名链接；原记录保留恢复时间。人工客户询盘回复和订阅确认等事务邮件仍可发送。

部署仅追加数据库结构，不重建数据库，不修改既有账号密码或邮箱数据。集成测试使用独立可销毁数据库和 SMTP 模拟器。
