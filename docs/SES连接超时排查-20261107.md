# AWS SES SMTP 连接超时排查

2026-11-07 读取阿里云现有配置，AWS SES 中继主机为 amazonaws.com，保存端口为 465，配置 active=0，bm_relay 无绑定记录。用户截图测试端口为 587。两种端口都不能通过根域连接 SES SMTP。

服务器解析 amazonaws.com 得到 15.197.250.250 和 166.117.149.112，与用户超时目标一致。连接该根域的 587、465、2587、2465 均超时，443 可连接。

在 billionmail-core-billionmail-1 容器内对下列地址的 587 STARTTLS 和 465 TLS 分别执行连接、证书校验、EHLO，四项全部通过，协商 TLSv1.3，EHLO 250，服务端支持 PLAIN、LOGIN：

- email-smtp.ap-southeast-1.amazonaws.com
- email-smtp.us-east-1.amazonaws.com

确定原因：SMTP 主机地址误填为 AWS 根域。应按实际 SES 区域填写官方 SMTP 端点。检查过程未发送邮件、未尝试猜测区域凭证、未变更线上 SMTP 路由或账号密码。等待用户确认 SES 区域后再设置正确地址并验证认证。
