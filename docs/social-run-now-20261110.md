# 社媒任务立即执行

任务列表操作列新增“立即执行”，沿用 social:publish 权限。草稿、已排期和暂停状态可启动；生成中、已完成和归档状态不可启动。任务须已生成并审核所有平台/市场版本，并选择有效授权主页。执行当前批次不跳过审核、账号权限、主页发布间隔、每日限额或平台重试等待。

已排期任务提前其原有记录；未排期任务创建当前批次记录并立即到期。以计划行锁和原始 cycle_at 标识批次，并发或重复点击复用同一批次。已发布、失败及结果不明的记录不会被自动重发，已提交记录继续等待平台确认。需要重试的异常发布仍通过发布记录中原有的核验流程处理。

重复计划以实际提前执行日推算下一周期，后续生成内容仍回到人工审核。未设置开始日期时，将首次立即执行日期固定下来，避免跨日重复点击变成新批次。

一并修复纯文字帖子中 JSON null 图片列表被误判为无效图片的问题；新保存的无图内容使用空数组。

验证包括独立 PostgreSQL 下的立即入队、未来任务提前、暂停任务启动、并发点击去重、工作线程模拟发帖、已发布/失败/未知结果保护、重试等待、审核和权限限制、重复计划及无日期批次；前端状态测试、多语言检查和构建。未向真实主页发布测试内容。
