# 拓客计划发信参数与关键词过滤

新建、编辑 AI 拓客计划增加邮件发送参数：关联 IP 预热、退订链接、跟踪点击、跟踪打开。新计划默认预热关闭，其余三个开启；已有未包含这些字段的计划保留原行为，即预热关闭、退订开启、跟踪关闭。

设置随计划保存，并作为运行配置的一部分冻结。生成的个人营销任务会在同一事务内保存相应字段及 IP 预热关联后，才进入可发送状态。预热使用原有 IP/收件服务商额度限制。关闭退订时，不再自动追加退订页脚及 List-Unsubscribe 邮件头；关闭跟踪时，不注入对应追踪像素或改写链接。无需增加 email_tasks.warmup 列，沿用现有预热关系表。

关键词过滤与联系人 Excel 导入复用同一个解析函数，改为多行文本框，支持英文逗号、中文逗号、英文分号、中文分号和换行，去除空白及重复项，并在输入框下方显示解析结果。保存、重新编辑后仍保持关键词数组，实际采集阶段继续按邮箱地址匹配并过滤。

本次不调用付费 AI，不向外部客户发送测试邮件；使用本地数据库、模拟 AI 和模拟 SMTP 验证持久化、任务传递及实际 MIME 内容。
