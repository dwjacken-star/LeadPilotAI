# QQ 回信 550 Mailbox does not exist 排查

从阿里云服务器分别查询 Google 和 Cloudflare 公共 DNS，两者均返回 best-maple.com 当前两条根域 MX：

| 优先级 | 目标 |
| --- | --- |
| 1 | feedback-smtp.ap-southeast-2.amazonses.com |
| 2 | mail.best-maple.com |

数字小的 MX 优先。截图 QQ 的 RCPT TO 550 来自第一条 AWS feedback 服务器，与现行解析一致。该服务用于 SES 自定义 MAIL FROM 的退信处理，并非本系统 sales 邮箱的收件服务器。

sales@best-maple.com 在数据库中存在、active=1；From 和 Reply-To 都为该地址；本机 SMTP RCPT 返回 250（未发送 DATA）。mail.best-maple.com 的 A 记录仍正确指向 47.237.67.184。

处理：在阿里云域名 DNS 控制台删除根域 @ 的 feedback-smtp MX，保留 @ MX 2 mail.best-maple.com。不要把 AWS feedback 地址作为根域收信的备用 MX。如果需要 SES 自定义 MAIL FROM，使用专门子域名（例如 bounce.best-maple.com），并在 AWS 控制台设置对应子域名，再在该子域名添加 MX 10 feedback-smtp.ap-southeast-2.amazonses.com 和 TXT v=spf1 include:amazonses.com ~all。

本次未变更 DNS；目前的服务器 root 访问不能直接操作域名 DNS 账户，未提供阿里云 DNS API 连接。数据库和 SMTP 中继均无须为此重建。

官方依据：https://docs.aws.amazon.com/ses/latest/dg/mail-from.html
