# 统一模板页面与角色权限

管理员与普通用户的 `/template` 入口现在共用同一完整页面，包含名称/类型/时间列表、搜索分页、HTML/拖拽新增、预览、编辑、复制、删除及受控 AI 编辑。

| 功能 | 角色权限 |
|---|---|
| 列表、搜索、详情、预览 | `template:list` |
| 新增 HTML/拖拽模板 | `template:create` |
| 复制可见的非 AI 模板 | `template:list` + `template:create` |
| 重命名、内容修改、拖拽编辑 | `template:update` |
| 删除 | `template:delete` |
| 新增 AI 模板 | `template:create` + `template:update`，以及已授权、已准备品牌资料的域名 |
| AI 对话、修改生成内容 | `template:update`，并检查关联模板数据范围 |

前端按操作权限和每条记录的后端授权标志显示按钮，后端独立校验。数据范围仍按本人、本部门、下级/指定部门或全部控制；统一页面不意味着普通用户可以读取管理员的全部模板。

新增模板归入当前账号部门和负责人，忽略客户端伪造归属。模板名称按部门唯一。列表、详情、修改和删除均使用操作绑定的数据范围。

AI 仅开放模板创作所需接口。新建会话记录创建者，禁止挂接其他人的会话；已共享的旧会话必须保证所有关联模板都在调用者的权限范围内。供应商密钥、全局配置、域名设置、任意会话枚举/删除接口不向普通成员开放。没有发件域名授权时仍可使用 HTML/拖拽，AI 品牌域名需由管理员单独授权。

验证包含真实 Vue 页面操作按钮、普通用户路由、跨部门读写拒绝、只读角色不能写入，以及 AI 会话路径和共享范围检查。隔离测试不发送真实客户邮件、不调用付费 AI。
