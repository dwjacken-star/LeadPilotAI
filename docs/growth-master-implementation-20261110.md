# Industry-neutral Growth Master implementation

Authorized scope: extend the existing Go/GoFrame, Vue and PostgreSQL application with one logical Growth Master, fourteen independently configured business skills and six durable workflows. Postiz is excluded. Preserve existing company, contact, mail, CRM, social, credentials and deployment configuration. Development, acceptance checks and Alibaba Cloud deployment are authorized.

Implementation order:
1. Additive industry-pack, workflow, evidence, prospect staging, approval, event and usage migrations; existing RBAC and department boundaries.
2. Typed skill contracts and a leased, checkpointed workflow executor with bounded calls, retries, cancellation, immutable snapshots and audit records.
3. Industry intelligence, public-company/contact discovery, ingestion-time verification, scoring, approved product/service matching and existing-CRM synchronization.
4. Multilingual content, explicit human approval and native MapleMail/Facebook/LinkedIn delivery handoff. Optional WhatsApp Cloud API template delivery and signed inbound events; disabled until configured.
5. Inbound inquiry processing, follow-up and daily analytics; integrated administration, XLSX templates/preview, English/Chinese/Japanese translations.
6. Disposable PostgreSQL lifecycle/authorization/budget/idempotency tests, frontend checks/build, binary build, deployment backup/rollback and authenticated live acceptance without unsolicited external messages or public posts.

Acceptance must distinguish local mocked-provider checks from real credentials, actual publication and inbox receipt. External-platform products and credentials are operator configuration, not fabricated successes. Existing production plans are never automatically enrolled into the new workflows.
