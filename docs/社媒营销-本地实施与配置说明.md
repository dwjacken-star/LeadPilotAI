# MapleMail 社媒营销实施说明

本次仅完成本地代码、构建和隔离测试，未更新阿里云、华为云，未改动线上数据库、DNS、邮件收发配置。平台默认停用，没有使用真实社媒凭证或发布内容。

## 管理入口与流程

现有管理台增加“社媒营销”，包含发布任务、发布记录、发布日历、执行记录、社媒账号、互动中心、效果分析。沿用当前账号、部门和角色体系，不增加独立后台。

1. 在资料中心维护并发布公司、产品、资料；或在任务中上传本次专用资料。
2. 新建任务，选择公司、平台、国家、语言、时区、当地发布时间、现有 AI 服务模型及写作要求。未授权社媒账号时可以先准备草稿。
3. 资料支持 XLSX、ZIP、PDF、DOCX、PPTX、TXT、Markdown、JPG、PNG、WebP。后台识别后可预览并批准；任务文件独立保存，归档进资料中心需要显式操作。XLSX 保留工作表、原行号和文本 SKU，分页预览，大表需选择本次产品行。
4. 按平台和国家语言分别生成内容，或手动撰写。左侧编辑、右侧预览，正文保留段落，图片通过有权限的文件接口预览。修改内容后需要重新审核。
5. 完成官方授权、选择主页，人工批准所有版本后提交排期。后端按当地时区换算 UTC，处理夏令时，不存在的当地时间会被拒绝。国家用于内容本地化，并不代表平台提供地域定向展示。
6. 工作进程执行排期，限制同一主页发帖间隔和 24 小时发布数量。重复任务在每轮完成后产生下一轮草稿，经人工审核后才能发布。
7. 同步授权范围内的评论、点赞及平台汇总指标；在互动中心标记处理状态、分配有权成员、进行受限 AI 分类。可跳转原帖处理互动。

当前发布支持文本、落地页链接、JPG/PNG 图片，不包含视频、直播、广告投放和 LinkedIn 个人动态。WebP 可作为资料识别，实际发帖请选 JPG/PNG；每张图片不超过 8 MB，每篇最多 10 张。ZIP 最多 1,000 项、解压合计 512 MB，拒绝目录穿越、符号链接和嵌套压缩包；XLSX 最多 50,000 行。大表正文生成最多使用 100 个选定产品行。

## 官方应用配置

超级管理员在“平台与分析设置”中填写应用信息。授权启用和真实发布为两个独立开关，授权成功不会自动打开发布。

| 配置 | Facebook | LinkedIn |
| --- | --- | --- |
| 应用 | Meta 开发者应用、Pages API 及所需审批 | LinkedIn 开发者应用、Community Management 产品及所需审批 |
| 账号 | 管理员具有内容创建权限的 Facebook Page | 管理员具有管理或内容管理权限的组织主页 |
| 授权回调 | `https://管理台域名/social/callback` | 同左 |
| 发帖权限 | `pages_show_list`、`pages_manage_posts` | `rw_organization_admin`、`w_organization_social` |
| 互动读取 | `pages_read_engagement`，用户评论另需 `pages_read_user_content` | `r_organization_social_feed`，以应用实际获准权限为准 |
| 组织统计 | `read_insights` | 组织管理/统计读取权限，以应用实际返回为准 |
| API 版本 | 初始配置 `v24.0`，可由管理员按已获准版本调整 | 初始配置 `202610`，可调整 |

Facebook Webhook 地址为 `https://管理台域名/social/webhooks/facebook`，取消授权回调为 `/social/deauthorize/facebook`。Webhook 校验 GET 口令与 POST HMAC 签名，只触发后续受控同步，不将原始通知作为客户数据保存。官方应用还需要按平台要求提供隐私政策、数据删除说明及审核材料，实际审核权限和额度不能由本系统替代。

OAuth state 有效期 10 分钟、单次消费，绑定当前用户、部门和应用配置；保存时核对实际授予的权限和主页管理能力。应用密钥、访问令牌和刷新令牌使用现有资料中心主密钥加密，浏览器只看到是否已配置；备份资料时应同时备份既有主密钥。令牌过期或权限撤回会阻断后续操作并要求重新授权；LinkedIn 返回可用 refresh token 时后端提供刷新操作，否则需重新连接。

## 权限

新增权限：`social:account:view/manage`、`social:plan:view/manage`、`social:content:edit/review`、`social:publish`、`social:interaction:view/manage/analyze`、`social:report:view`、`social:settings`。仍按现有角色选择 self、department 等数据范围。配置只允许超级管理员；授予其他部门主页访问前，需要确认其成员属于该主页的授权管理团队。拥有全局业务数据范围也不能直接绕过跨部门主页授权。

后台接口逐项检查权限和资源范围；任务文件不能靠猜 UUID 下载；排期执行时重新加载账号权限、主页授权、令牌状态、审核版本和来源快照。资料中心的产品、文件选择另需既有 `product:list`、`material:list` 权限。

## 发布和统计的准确性

发布记录冻结正文、图片、来源版本和发送策略。数据库唯一约束与任务租约阻止重复排期和重复领取，同一主页的发送操作串行检查间隔。AI、同步与发布采用独立工作循环，批量内容按版本分段生成。

HTTP 超时、5xx、提交成功却缺少帖子 ID、进程中断等结果不明的请求标记为 `unknown`，不会盲目自动重发。可填写实际帖子 ID 回查归属及状态；只有确认平台未发布后才能显式重试。平台返回 429 时按退避时间等待；权限失败则阻断并提示重新连接。LinkedIn 返回帖子 ID 先标记已提交，回查状态后才标记已发布。

效果分析使用官方接口返回的计数，展示更新时间和数据来源。不提供的指标显示 `—`，不会伪装为 0。汇总只统计有值的记录，并显示覆盖数量；各帖触达人数不能相加解释为独立用户数。报表按帖子展示并支持 XLSX 汇总导出，当前界面不提供历史趋势图。单次报表最多 500 条、日历最多 93 天/1,000 条；列表固定 20 条，资料和主页选项支持搜索与分页。互动同步每批覆盖 20 篇帖子，优先更新尚未统计或最久未更新的帖子，评论和点赞各有分页上限，并标记采集范围。

## AI 与平台数据边界

写作仅使用已发布的公司产品资料及人工批准的任务材料，内部资料不能用于对外营销。表格的成本、采购、银行、密钥等字段在写作来源中剔除；文档使用已审阅的识别事实，不直接将完整原文作为发布资料。最终正文仍需人工审核。

互动分析默认关闭。管理员需选择模型并确认适用的数据处理、保留和禁止训练条件后才可启用。AI 仅返回主题、情感、人工处理优先级、置信度和原文证据；成员身份不送入分类提示。

根据 LinkedIn 官方规则，第三方评论不用于生成/改写回复、帖子或私信，不转化为 CRM 客户名单，不导出成员明细，不推断个人画像。评论及其分析按 48 小时缓存清理，成员名称按 24 小时清理；内容编辑或删除会清除旧分析。汇总统计保留不超过一年。互动处理为内部工作队列，不提供自动评论回复功能。

## 本地验证与后续验收

验证使用独立 PostgreSQL 临时数据库，测试结束删除该临时库。迁移反复执行验证通过，新增表和索引采用增量方式，无清空旧业务数据逻辑。没有对线上库执行迁移。

已覆盖：默认停用、密钥加密、OAuth 回调与重放防护、实际权限识别、私有文件、工作表/前导零、ZIP 安全边界、来源审核、排期幂等、夏令时、模拟文本和图片发布、超时结果、互动分页/去重/变更/到期、真实 HTTP 上传下载、XLSX 报表、角色访问、前端指标与多语言检查。浏览器验证了中文新建任务、草稿保存、双平台内容编辑、段落预览和审核链路。真实平台接口尚未使用获批应用验证，正式配置后仍需各平台授权、图片发布、统计读取、令牌过期及撤权验收。

本地命令（在 `core` 下；Go 1.23.2）：

```text
go test ./internal/service/social ./internal/controller/social
go build -o ../.tools/maplemail-social-linux main.go
```

数据库测试需设置 `BM_TEST_PG_HOST`、`BM_TEST_PG_PORT`、`BM_TEST_PG_PASSWORD`，必须指向可创建和删除临时测试数据库的本地测试实例。未提供配置时数据库测试会跳过。生产目录已有 `run_dev.go`，构建正式入口使用 `main.go`，不能将两个 main 同时编译。

前端在 `core/frontend`：`npm run build`、`npm run i18n:check`、`node --experimental-strip-types --test tests/social.test.mjs`。仅构建不会执行部署脚本。

最终检查记录（2026-11-09）：社媒服务及 HTTP 控制器测试通过，现有 growth 服务、growth HTTP 控制器、governance 回归通过；正式 `main.go` 的 Linux 构建通过；前端生产构建、定向 ESLint、2,186 个中英日翻译键对齐检查通过。浏览器另外验证了旧任务空数组恢复、关闭按钮翻译、私有图片上传和批准、图片 Blob 预览实际加载。发布适配器验证使用模拟官方响应，没有真实发帖。

官方依据：[Meta Pages API](https://developers.facebook.com/documentation/pages-api/posts)、[LinkedIn Posts API](https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/posts-api?view=li-lms-2026-10)、[LinkedIn AI Policy](https://learn.microsoft.com/en-us/linkedin/marketing/developer-ai-policy?view=li-lms-2026-10)、[LinkedIn Data Storage Requirements](https://learn.microsoft.com/en-us/linkedin/marketing/data-storage-requirements?view=li-lms-2026-10)。平台可用权限、配额和数据规则以应用启用时官方要求为准。
