# 社媒图片与秒级排期

排期日期控件可选择年月日时分秒，目标市场时刻也支持秒。存储沿用日期加市场当地时刻，后端按市场时区转换为时间戳，并拒绝不存在的夏令时时刻。原有 HH:mm 配置继续有效。日期控件只改日期时保留各市场独立时刻；修改时刻时应用到所有市场，再可分别调整。

内容生成与审核可一次上传多张 JPG/PNG，每条内容最多10张，每张8MB。支持预览、排序、移除及资料库选择。新上传图片先存为待审核素材，保存内容后由审核权限用户连同正文审核，发布时仍检查审核状态。Facebook attached_media 和 LinkedIn multiImage 保留图片顺序。

AI 图片处理复用智能拓客 AI 服务的 HTTPS 地址、加密密钥和每日用量限制，单独发现并选择图片模型。采用 [OpenAI Images Edit 协议](https://developers.openai.com/api/reference/resources/images/methods/edit)，每张图片独立入队，使用相同的风格要求与目标尺寸；记录服务返回的 token 用量。图片结果使用独立文件保存，原图及历史结果保留。用户选择结果后必须保存并重新审核，处理任务不会自行改动已审核内容或排期快照。

源图须允许 AI 使用。图片编辑仅接收经过权限和格式校验的本地图片，不从模型返回的 URL 下载图片；服务响应须包含 base64 图片。异常任务不会自动重做付费图片请求。使用其他兼容服务时，需确认服务提供 Images Edit 和所选模型权限。

未选择源图且填写图片要求时，同一 `process_images` 接口使用 `images: []` 入队提示词生图，经配置服务的 `/images/generations` JSON 协议生成一张候选图。生图与编辑共用模型选择、预算、尺寸限制、base64 校验和候选素材审核流程，不新增独立应用；生成的插画不得冒充真实产品照片或虚构产品规格。服务需支持 Images Generation，未支持时任务明确失败，不自动改用浏览器或其他服务。生图结果不会自动替换已审核正文、图片或投递快照。

验证包括独立 PostgreSQL 下的上传、审核、队列去重、后台任务处理、候选图保留、权限隔离、模拟 Facebook/LinkedIn 多图发布请求；AI 协议模型发现、multipart 文件与 MIME、预算和 token 用量、错误脱敏；秒级/旧分钟格式/时区/夏令时测试，前端状态测试、多语言检查和构建。

验证阶段未调用真实付费图片生成，未发布真实平台内容。上线状态以 deploy 目录中的部署记录为准。
